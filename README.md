  # Sistema de Compras

Sistema web interativo desenvolvido com HTML, CSS e JavaScript (vanilla), com integração de APIs públicas para gamificação e localização em tempo real.

Acesse o projeto:  
https://maria0x1.github.io/sistema-compras/

---

## Sobre o projeto

O Sistema de Compras é uma aplicação web que busca tornar o processo de criação de listas de compras mais dinâmico e menos repetitivo.

A proposta do projeto é reduzir o esforço manual ao montar listas, utilizando recursos como automação, dados externos e elementos de gamificação para melhorar a experiência do usuário.

---

## Objetivo

- Evitar a escrita repetitiva e cansativa de listas de compras  
- Tornar o processo mais rápido e interativo  
- Aplicar conceitos de automação no front-end  
- Explorar integração com APIs públicas  

---

## Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- APIs públicas  

---

## Funcionalidades

- Criação dinâmica de listas de compras  
- Redução de repetição na entrada de dados  
- Integração com APIs externas  
- Recursos de gamificação  
- Localização em tempo real  
- Interface simples e interativa  

---


---

## Diferenciais

- Uso de JavaScript puro, sem frameworks  
- Integração com APIs para enriquecer a experiência  
- Aplicação de gamificação em um problema cotidiano  
- Foco em usabilidade e produtividade  

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:

- Manipulação do DOM com JavaScript  
- Consumo de APIs (fetch/async/await)  
- Organização de lógica no front-end  
- Criação de interações dinâmicas  
- Pensamento voltado à experiência do usuário  

---

## Limitações

- Não possui backend próprio  
- Dependência de APIs externas  
- Algumas funcionalidades podem depender de conexão com internet  

---

## Melhorias futuras

- Persistência de dados (localStorage ou banco de dados)  
- Sistema de contas/login  
- Histórico de listas  
- Sugestões automáticas de produtos  
- Versão mobile mais otimizada
